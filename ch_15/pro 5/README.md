# Project 5: Stack (Separate Header and Source)

## Description
This project is a solution to Programming Project 5 from Chapter 15 (based on Chapter 10, Project 6). 
It modifies the RPN Calculator (Stack program) to use a separate `stack.h` and `stack.c` files, following the modular design described in Section 15.2. 

## Files
* `main.c`
* `stack.c` / `stack.h`

## How to Compile & Run
Using GCC in the terminal:
```bash
gcc main.c stack.c -o calculator
./calculator
